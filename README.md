# Texas Aerial Robotics

Website for Texas Aerial Robotics, an undergraduate research organization at the University of Texas at Austin that designs, builds, and programs fully autonomous drones.

## Stack

- **Next.js** (App Router) + TypeScript
- **Tailwind CSS**
- `@fontsource` for Inter, Sora, and Space Grotesk
- `phosphor-react` for icons
- Light/dark theming via a custom `ThemeProvider`

## Pages

| Route | Contents |
|---|---|
| `/` | Landing page |
| `/about` | Organization overview |
| `/projects` | Drone platforms and research work |
| `/partners` | Sponsors and partners |
| `/contact` | Contact form |

## Running locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm start
```
